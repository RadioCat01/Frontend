## The Three Migration Files Explained

### 1. InitialCreate.cs (Main Migration File)
**This is what you see and can edit:**

```csharp
namespace EnhanzerAPI.Migrations
{
	public partial class InitialCreate : Migration
	{
		// This runs when you do: Update-Database
		protected override void Up(MigrationBuilder migrationBuilder)
		{
			// Creates the Location_Details table
			migrationBuilder.CreateTable(
				name: "Location_Details",
				columns: table => new
				{
					Id = table.Column<int>(...).Annotation("SqlServer:Identity", "1, 1"),
					LocationCode = table.Column<string>(...),
					LocationName = table.Column<string>(...)
				},
				constraints: table =>
				{
					table.PrimaryKey("PK_Location_Details", x => x.Id);
				});
		}

		// This runs if you ever need to undo: Remove-Migration
		protected override void Down(MigrationBuilder migrationBuilder)
		{
			migrationBuilder.DropTable(name: "Location_Details");
		}
	}
}
```

**What each part does:**
- `Up()` → Apply the migration (create table)
- `Down()` → Rollback the migration (drop table)
- Name `InitialCreate` → Describes what this migration does

## Database Schema Created

### Location_Details Table

```sql
CREATE TABLE [Location_Details] (
	[Id] int NOT NULL IDENTITY(1,1),
	[LocationCode] nvarchar(max) NOT NULL,
	[LocationName] nvarchar(max) NOT NULL,
	CONSTRAINT [PK_Location_Details] PRIMARY KEY ([Id])
);
```

**Column Details:**

| Column | Type | Constraints | Purpose |
|--------|------|-------------|---------|
| `Id` | `int` | PRIMARY KEY, IDENTITY(1,1) | Auto-incrementing unique identifier |
| `LocationCode` | `nvarchar(max)` | NOT NULL | Location code (e.g., "LOC001") |
| `LocationName` | `nvarchar(max)` | NOT NULL | Location name (e.g., "Main Branch") |

**Example Data That Will Be Inserted:**

```
Id  | LocationCode | LocationName
----|-------------|------------------
1   | LOC001      | Main Branch
2   | LOC002      | Mumbai Warehouse
3   | LOC003      | Delhi Hub
```
